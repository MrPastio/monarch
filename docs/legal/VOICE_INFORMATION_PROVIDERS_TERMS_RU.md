# Условия быстрых информационных карточек Voice

Версия: `2026-08-29.1`  
Дата: `2026-08-29`

## Что включается

После отдельного явного согласия «Упрощённый режим» может обращаться к двум независимым внешним источникам:

- **Open‑Meteo** — поиск города и прогноз погоды;
- **Национальный банк Украины (НБУ)** — официальный курс иностранных валют к гривне.

Согласие относится только к этой версии, этим providers и описанным ниже данным. Оно не разрешает облачный chat, web search, новости, пробки, рекламу, телеметрию или передачу других данных. Смена provider, получателя либо состава данных требует новой версии и нового согласия.

## Какие данные уходят

Для погоды Monarch передаёт Open‑Meteo только одно из двух:

- введённое в настройках или произнесённое название города; либо
- широту и долготу, полученные от ОС только в момент погодного запроса, если пользователь отдельно выбрал «Геопозиция устройства».

Затем Monarch передаёт Open‑Meteo координаты выбранного места, список погодных показателей, timezone `auto` и период до трёх дней. Точные координаты не записываются в настройки, историю или собственную телеметрию Monarch.

Для курса Monarch обращается к публичному API НБУ за текущей таблицей официальных курсов. Текст голосовой команды, история чата и размер конвертации в НБУ не передаются; расчёт суммы выполняется локально.

Оба provider неизбежно получают IP address, время запроса и обычные технические сетевые данные. Monarch не добавляет к запросам историю, память, personality, файлы, вложения, контакты, содержимое Monarch Safe, секреты или стабильный пользовательский identifier.

## Хранение и условия providers

Open‑Meteo сообщает, что server logs бесплатного API могут содержать координаты и удаляются через 90 дней. Данные API распространяются по CC BY 4.0 и показываются с атрибуцией. Бесплатный endpoint разрешён только для некоммерческого использования и имеет лимиты; коммерческий релиз Monarch обязан использовать подходящий платный endpoint/API key либо заменить provider после нового согласия.

- [Open‑Meteo Terms & Privacy](https://open-meteo.com/en/terms)
- [Open‑Meteo Licence](https://open-meteo.com/en/license)
- [Open‑Meteo Weather API](https://open-meteo.com/en/docs)
- [Open‑Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api)
- [API НБУ](https://bank.gov.ua/ua/open-data/api-dev)

Независимые providers могут менять доступность, точность, лимиты и документы. Monarch показывает подтверждённый ответ источника, не выдумывает результат при ошибке и не гарантирует безошибочность прогноза или будущую доступность API.

## Управление

Разрешение по умолчанию выключено. Его можно отозвать в настройках Voice; после отзыва новые внешние запросы fail‑closed, а локальные команды устройств продолжают работать. Полный Voice не запускается автоматически.
